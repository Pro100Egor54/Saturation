# Saturation
Репозиторий создан командой из СУНЦ НГУ для хакатона.
Решаемая задача выгляит следующим образом:
# Кейс А. Лимонадный завод
## Заказчик: 
Кафе хочет делать свой газированный лимонад — 200 литров в час в смену.

## Процесс: 
Cироп из бака насосом по трубке в смеситель → туда же вода → смесь в колонну газирования, где снизу идёт CO₂ → готовый лимонад → бак розлива, откуда самотёком по бутылкам.

Целевое число: производительность 200 л/ч при насыщении CO₂ не менее 95 % и без воздуха в бутылках.

# 1. Параметры оборудования из ТЗ
## Параметры оборудования

| Узел | Параметры из ТЗ |
|:---|:---|
| **Бак сиропа** | Объём: 50 л; диаметр: 350 мм; сливное отверстие: Ø12 мм (в нижней части); плотность сиропа: ρ = 1300 кг/м³; динамическая вязкость: μ = 0,1 Па·с. |
| **Насос сиропа** | Тип: дозирующий; производительность: 33 л/ч; соотношение сиропа и воды: 1:5; напор: 6 м вод. ст. (≈ 60 кПа); КПД: 0,4. |
| **Трубка сиропа** | Внутренний диаметр: Ø8 мм; длина: 6 м; подъём к смесителю: 2 м. |
| **Насос воды** | Производительность: 167 л/ч; напор: 10 м вод. ст. (≈ 100 кПа); КПД: 0,5. |
| **Трубка воды** | Внутренний диаметр: Ø12 мм; длина: 10 м; подъём: 2 м. |
| **Смеситель** | Объём бака: 100 л; диаметр: 450 мм; мешалка с наклонными лопастями; диаметр мешалки: 150 мм; частота вращения: 120 об/мин; мощность двигателя: 50 Вт; плотность смеси: ρ = 1050 кг/м³; динамическая вязкость: μ = 1,5 мПа·с. |
| **Колонна газирования** | Диаметр: 200 мм; высота жидкости: 1,2 м; расход CO₂: 10 л/мин; подача газа через диск с отверстиями; диаметр пузырьков: ≈ 3 мм. |
| **Бак розлива** | Объём: 20 л; диаметр: 250 мм; слив самотёком через отверстие Ø12 мм в разливочный шланг. |
