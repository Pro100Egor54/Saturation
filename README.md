# Saturation
Репозиторий создан командой из СУНЦ НГУ для хакатона.
Решаемая задача выгляит следующим образом:
# Кейс А. Лимонадный завод
Заказчик: кафе хочет делать свой газированный лимонад — 200 литров в час в смену.

Процесс: сироп из бака насосом по трубке в смеситель → туда же вода → смесь в колонну газирования, где снизу идёт CO₂ → готовый лимонад → бак розлива, откуда самотёком по бутылкам.

Целевое число: производительность 200 л/ч при насыщении CO₂ не менее 95 % и без воздуха в бутылках.
