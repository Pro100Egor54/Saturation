# Saturation
Репозиторий создан командой из СУНЦ НГУ для хакатона.
Решаемая задача выгляит следующим образом:
# Кейс А. Лимонадный завод
Заказчик: кафе хочет делать свой газированный лимонад — 200 литров в час в смену.

Процесс: сироп из бака насосом по трубке в смеситель → туда же вода → смесь в колонну газирования, где снизу идёт CO₂ → готовый лимонад → бак розлива, откуда самотёком по бутылкам.

Целевое число: производительность 200 л/ч при насыщении CO₂ не менее 95 % и без воздуха в бутылках.

# 1. Параметры оборудования из ТЗ
Узел	Параметры из ТЗ
Бак сиропа	50 л, D = 350 мм, слив Ø12 мм внизу; сироп: ρ = 1300 кг/м³, μ = 0,1 Па·с
Насос сиропа	Дозирующий, 33 л/ч (1 часть сиропа на 5 частей воды), напор 6 м вод. ст. (≈ 60 кПа), КПД 0,4
Трубка сиропа	Ø8 мм, длина 6 м, подъём на 2 м к смесителю
Насос воды	167 л/ч, напор 10 м вод. ст. (100 кПа), КПД 0,5
Трубка воды	Ø12 мм, 10 м, подъём 2 м
Смеситель	Бак 100 л, D = 450 мм, мешалка с наклонными лопастями d = 150 мм, 120 об/мин, мотор 50 Вт; смесь ρ = 1050, μ = 1,5 мПа·с
Колонна газирования	D = 200 мм, высота жидкости 1,2 м, CO₂ 10 л/мин через диск с отверстиями (пузырьки ≈ 3 мм)
Бак розлива	20 л, D = 250 мм, слив самотёком через отверстие Ø12 мм в разливочный шланг
